## How to read it

- **Implementation** means the PR changes product code and includes its stated checks. Read the PR for exact scope and current CI/merge status; several original issues contain additional work beyond the bounded fix.
- **Proposal / evidence plan (draft)** means the PR describes decisions, contracts or an unexecuted verification protocol. It is not shipped functionality, an approved design or a completed playtest. These issues remain open.
- Nothing in this index authorizes live deployment, paid provider experiments, changes to active saves or unperformed Windows UI checks.
